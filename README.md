# 西南交通大学犀浦校区 · 数字孪生（非官方演示）

单文件 3D 校园孪生：双击 `西南交大犀浦校区数字孪生.html` 即可在浏览器打开，无需联网、无需安装。

## 能做什么
- **真实轮廓**：261 栋建筑（校内 108 栋）、470 条道路、水系、球场、跑道、树行，均来自 OpenStreetMap（2026-11-04 抓取）。
- **一天的校园**：拖动底部时间轴或点播放，太阳东升西落、夜晚窗户按占用率亮灯，道路上的橙色粒子表示户外人流（上下课、饭点高峰）。
- **三种视图**：常规 / 人流热力（按建筑占用率着色）/ 能耗（按单位面积负荷着色）。
- **点击建筑**：查看层数、建筑面积、当前人数、负荷与 24 小时占用曲线；左侧可按类别筛选、按楼名搜索。
- **地标**：詹天佑像、竢实扬华碑、校史馆、SS1/DF4/JS 机车与磁浮 CFC-01 展品等。

## 数据口径（重要）
| 内容 | 来源 |
|---|---|
| 建筑轮廓、楼名、道路、水系、地标位置 | OpenStreetMap，真实 |
| 层数 / 高度 | 仅 1 栋在 OSM 有标注，其余**按建筑类型估算** |
| 人数、占用率、能耗 | **作息模型推算的演示数据**，不是实时数据 |

本项目与西南交通大学官方无关。地图数据 © OpenStreetMap contributors，按 ODbL 许可使用。

## 目录
- `src/index.html` 页面源码；`data/xipu.osm` 原始 OSM 数据；`data/campus.json` 转换后的本地米制坐标
- `tools/convert.py` OSM → JSON；`tools/build.py` 打包成单文件；`tools/render.js` 逐帧渲染视频
- 加 `?video=1` 打开为视频模式（无界面，逐帧确定性渲染）

## 接入真实数据
把 `occOf()` / `loadOf()` 换成从门禁、一卡通、能耗监测系统读取的接口即可，渲染层（状态纹理）不用改。
